MYDOS 1.0 — designed for humans and AI together

一個從零開始用 C 寫的 64 位元 DOS 風格作業系統。上面的黑色畫面不是錄影：瀏覽器裡真的跑著一台虛擬 PC，從 BIOS、開機程式一路開進 MYDOS 核心。

點一下黑色畫面就能打字，或直接點這些指令：
HELP DIR \BIN DEMO Ada GUESS LIFE CRASH MEM TIME

小技巧：↑ ↓ 叫回之前的指令；Ctrl+C 結束程式； COPY CON NOTE.TXT 打字存檔，Ctrl+Z 再 Enter 結束。

功能：FAT16 硬碟 · DIR/CD/COPY/DEL · 批次檔與 AUTOEXEC.BAT · 程式在 ring 3 受保護執行（CRASH 示範）· 藍色當機畫面（PANIC）。
C 槽的變更只存在這個分頁；重新整理就會重開機。建議使用電腦版 Chrome 或 Edge。 · GitHub
